# Laravel Blog — CRUD Exercise

A blog management application built with **Laravel, PHP, and MySQL** to practice CRUD operations and REST API development.

## Features
- Create, view, and edit posts
- Soft Delete, Restore, and Force Delete
- Input validation and JSON responses
- Eloquent ORM and database migrations
- Pagination
- Blade templates and Bootstrap UI

## Tech Stack
- PHP & Laravel
- MySQL
- Blade & Bootstrap
- REST API

## Live Demo
http://myblogsystem.atwebpages.com/

## Installation
```bash
git clone <repository-url>
cd <project-folder>
composer install
```

Configure your `.env` database settings, then run:

```bash
php artisan key:generate
php artisan migrate
php artisan serve
```
